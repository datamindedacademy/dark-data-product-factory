# Intake

Turns the request into a spec: for each question, how to compute the answer. Says so when the data
can't answer it.

**In** `input/issue.md` **Out** `output/spec.json`

**Try**
- Fernhill's business rules from [interviews.md](../../docs/interviews.md), as a skill
- The definitions written once, for the other agents to reuse
- [ODCS](https://bitol-io.github.io/open-data-contract-standard/) to describe what the answers guarantee
